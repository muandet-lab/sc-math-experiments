# Case 5 confirmatory benchmark: locked setup

Locked **2026-10-01 19:29 UTC**, before any confirmatory model generation. This is a new benchmark; the earlier Case 5 pilots are exploratory and are not pooled with it. No smoke test or confirmatory model run was performed at lock time.

## Question and predictions

We test whether a missing quantity in a short arithmetic story elicits an unsupported zero default. The primary outcome is an unqualified final integer equal to the answer obtained by replacing the missing quantity with zero. Truncated and unparseable responses are separate outcomes and remain in the denominator; a completed-response sensitivity analysis will exclude them and report both denominators.

1. **Salience gradient.** For each missing slot and chain length, the zero-default rate should be highest when the quantity is only implicit, lower with “some,” and lowest with “an unspecified number.” Initial-state omission is the sharpest test. Wording is not perfectly symmetric across slots: the initial implicit clause is absent, whereas an implicit transfer still names the action. We therefore report slot interactions and do not interpret the across-slot main effect as a pure causal effect of slot.
2. **Instruction dissociation.** The user-appended assumption instruction should improve the separate marked pocket/box condition more than the omitted-start condition. The contrast is the marked-minus-omitted change in accuracy (and the inverse change in zero-default errors). A positive contrast supports cue-dependent correction. If neither improves, instruction persistence is uninformative; if both improve, the prior pilot does not replicate.
3. **Scale.** Direction is deliberately open: the zero-default pattern may shrink, persist, or change form as Qwen3 grows. Fit the size trend only within Qwen3. OLMo 3 Think 7B and **Olmo-3-32B-Think** are two comparison points, not a fitted family curve.

The answerability-minus-solving accuracy gap is descriptive evidence for detecting insufficiency without using it while solving. Trace codes describe observable text; they cannot prove an internal causal mechanism. These tests alone do not license the term *spurious correlation*; that requires a separate corpus-frequency analysis and OLMo stage-checkpoint work.

## Frozen design

Seed **20261001** yields 36 fresh bases, balanced across shells/coins/cards/marbles and receive/give, earn/spend, find/lose verb pairs. Each base has 18 factorial items (3 missing slots × 3 salience levels × 2 action-chain lengths), one infeasible-zero-start item, one marked pocket/box challenge, and three solvable controls (complete, explicit zero start, and net change with unknown initial state): **23 items/base, 828 items**. The extra marked challenge preserves the completed-error positive-control pocket from the OLMo follow-up. Every item has its expected answer and a zero-default arithmetic value. Gold and zero-default must differ on every underdetermined challenge and on the complete control. They necessarily coincide on the zero-start and net-change controls because zero is explicitly given or initial state cancels; these are excluded from zero-default error measurement.

Every item is presented in two fresh-call tasks, solving and unique-answerability checking, and two instruction placements, no added instruction and the user-appended instruction from the pilot. Thinking is enabled for Qwen and native for OLMo. Sampling is temperature 0.6, top-p 0.95, Qwen top-k 20, with **16,384** output tokens and 20,480 model context tokens. Four samples/prompt for models through 8B; two samples/prompt for 14B and 32B. This is **86,112** planned solve/check responses. The prefill assay has 72 independent probes (omitted versus explicit initial for each base), run once on each of eight models. It compares log probability of the single-token continuations ` 0` and ` <received>` after a fixed assistant thinking-prefix completion. It is an auxiliary forced-prefix measure, not spontaneous reasoning or calibrated evidence of a hidden prior.

The scorer [score_case5_confirmatory.py](score_case5_confirmatory.py) is version `case5-confirmatory-v1`. It requires a completed `</think>` segment and a final answer (or terminal standalone abstention), accepts a correct affine expression in `x`, and assigns exactly one of `correct`, `zero_default`, `other_error`, `unparseable`, `truncated`. ## Analysis locked before data

Report zero-default rate, accuracy, truncation, and unparseability in each slot × salience × chain × instruction cell. The six per-model figures are overall zero-default rate, explicit-minus-implicit accuracy, marked-minus-omitted instruction uplift, answerability-minus-solving accuracy on omitted starts, prefill zero-versus-received log odds, and over-abstention on the three controls. Include both absolute rates and uncertainty intervals in the final written analysis. The main mixed-effects logistic test uses zero-default as outcome, salience × instruction × slot, chain length and model as fixed effects, and base/item random intercepts; a targeted marked-versus-omitted × instruction model tests the positive-control dissociation. Qwen-only model-size trend is separate. Treat model nonconvergence or separation as a reporting limitation, not a reason to change cells or hypotheses after the fact.

For each model, sample up to 20 completed omitted-start zero-default failures for blind two-coder trace review. Codes: D1 explicit zero, D2 missing start noticed then defaulted, N no initial-state representation in the trace, C net-change treated as final state, O other. Flag whether the trace refers to the instruction. Report Cohen’s κ, adjudicate disagreements, then label a model `default-pattern` if D1+D2 ≥60%, `nonrepresentation-pattern` if N ≥60%, else `mixed`. This label applies to observed traces only.

Coding order: assign **D2** when the trace explicitly recognizes the missing start and then supplies or behaves as if it were zero; assign **D1** when it explicitly states or writes a zero start without first recognizing the omission. Assign **C** when it explicitly calls the arithmetic difference a *change* and then relabels it as the final holding. Assign **N** when it immediately calculates from the transfer numbers without referring to a prior holding or to net change. Use **O** for no clear match, multiple irreducible patterns, or a trace too sparse to classify. The model label is a description of the adjudicated trace sample, not a claim that unseen internal state is absent.
